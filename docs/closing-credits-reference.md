# Closing-credit references

Reviewed October 5, 2026.

- [How I Met Your Mother end credits (2006)](https://www.youtube.com/watch?v=A5ykEPFJ2KY): inspected the actual closing cards, including the unit production manager and assistant directors at about 0:12, costume/make-up/hair at 0:16, and sound/post-production at 0:21. This is a filmed television broadcast with altered audio pitch, so it is a visual reference, not an audio reference.
- [Series cast and crew](https://www.imdb.com/title/tt0460649/fullcredits/): reference for the crew billing and names.

## Adaptation

The reference cuts between stationary black cards with centered, lowercase, chunky white serif lettering. Roles are smaller than names; multiple departments stack vertically with generous space. The app uses Caprasimo for a similar rounded serif shape, with local serif fallbacks.

Four cards run for twelve seconds: executive producers/director, production/assistant directors, costume/make-up/hair, and music. This is an abbreviated sequence, not a complete transcription. It replaces the episode title, number and closing slogan entirely. The existing original synthesized theme returns underneath, with no imported recordings or footage.

As in the opening, every name is fictional and selected from sound-alike variants. Examples include Penelope Freeland (Pamela Fryman), Suzie Maren Greenfield (Suzy Mamann Greenberg), Mitchell Shay (Michael Shea), Krista Hewitt (Christy Hughes), Susannah Presto (Susanna Puisto), Lena Jeffries (Lona Jeffers), Tina Porter-Lindell (Tena Parker-Liddiard), Jonas Swainhart (John Swihart), and The Statics (The Solids). The executive producers retain the creator aliases selected for that episode's opening.

Cards cut without scrolling, zooming or fading, including with reduced motion. The playback clock controls their timing even when music is disabled. Pause freezes the card and audio; skipping clears the credits and music before playback continues.
