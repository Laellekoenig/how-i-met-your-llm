# Playbook title-card reference

The original show's play introductions use a full-frame pale cream field, a dark stepped rectangular border
with a lighter inset border, and large black calligraphic lettering. The play name is usually the only text;
“The” sits on its own line. The edit then returns to the characters to explain or demonstrate the play.

Visual reference: [Every Play in the Playbook — How I Met Your Mother](https://www.youtube.com/watch?v=Ni40mZCl32A&t=2s).
The “Don't Drink That” title is visible around 00:02. This is a fan-posted compilation of footage from the show,
used to inspect the original cards. [FOX Home Entertainment's Playbook clip](https://www.youtube.com/watch?v=iVeE3d5tpYo)
provides additional context for the book prop.

Our card uses CSS for the cream field, an original SVG stepped frame and Pinyon Script lettering with system
calligraphic fallbacks. No footage or reference image is bundled. It cuts in without an entrance animation,
holds briefly based on the title's length, then clears before the spoken explanation or reaction.

Only Playbook cards are rendered or offered by the playground. The episode validator retains older insert
kinds so existing pre-written files and replay beat indices stay valid. Their spoken lines, reactions and laughs
remain in the scene; their cards, reveals, reading delays and associated sounds are removed. Legacy Playbook
steps remain accepted but are not drawn and do not extend the card's duration.

Verified in the running app: all nine distinct Playbook titles in the episode catalog fit within the frame,
as do the short “The Scuba Diver” and longer “The Lorenzo Von Matterhorn” reference titles. The spoken
explanation starts with the card cleared. The MacLaren's wide, close-up, two-shot and reverse coverage
remain visible; an over-the-shoulder request uses the director's existing close-up fallback for this pairing.
